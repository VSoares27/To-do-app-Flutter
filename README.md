# Flutter To-Do

Mobile to-do app: SQLite persistence, categories, status/category filters,
optional due date & time, scheduled local notifications.

## How to run

This repository ships the Dart sources, `pubspec.yaml` and the Android
manifest. The platform folders (`android/`, `ios/`) are generated by Flutter, so
create them once:

```bash
# 1. Generate the platform scaffolding into a temp project
flutter create --org com.example --project-name flutter_todo .

# (flutter create keeps existing lib/, pubspec.yaml and AndroidManifest.xml
#  files that are already present; review any prompt before overwriting.)

# 2. Install dependencies
flutter pub get

# 3. Run on a connected device / emulator
flutter run
```

If `flutter create` overwrites `android/app/src/main/AndroidManifest.xml`,
re-apply the version in this repo (it adds the notification permissions and the
flutter_local_notifications receivers).

### iOS extra step

In `ios/Runner/AppDelegate.swift`, register the local notification delegate:

```swift
if #available(iOS 10.0, *) {
  UNUserNotificationCenter.current().delegate = self as? UNUserNotificationCenterDelegate
}
```

## Structure

```
lib/
  main.dart                  app bootstrap, provider, theme
  models/                    Task, Category
  data/                      AppDatabase (sqflite), TaskRepository, CategoryRepository
  services/                  NotificationService (flutter_local_notifications + timezone)
  state/app_state.dart       ChangeNotifier: tasks, categories, filters
  screens/                   task_list_screen, task_editor_screen, category_screen
```

See `BUILD_LOG.md` for the development history and design decisions.
